## 🌟 About the Project

**Samanvaya** is a modern digital marketplace designed to bring buyers and sellers together through a unified online platform.

The platform focuses on creating a seamless digital shopping experience with a modern interface, easy navigation, and an accessible marketplace environment.

The name *Samanvaya* represents connection, coordination, and togetherness, reflecting our vision of building a connected digital marketplace.

## 🎯 Project Objectives

- Create a unified digital marketplace.
- Connect buyers and sellers through an online platform.
- Provide a simple and user-friendly shopping experience.
- Develop a responsive and modern web interface.
- Make product discovery easier and more convenient.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/Saneed-Nayak/Samanvaya-Digital-Marketplace.git
```

### 2. Navigate to Project Directory

```bash
cd Samanvaya-Digital-Marketplace
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

### 5. Build for Production

```bash
npm run build
```

### 6. Preview Production Build

```bash
npm run preview
```
